# F1 Dynasty Manager — Event System v0

## Purpose

Este documento define cómo funciona el sistema de eventos del mundo.

Objetivo:

* hacer que el mundo se sienta vivo
* generar contexto alrededor de la simulación
* crear narrativas emergentes
* evitar eventos arbitrarios

Principio rector:

```text
Events should emerge from systems,
not from scripts.
```

---

# Event Philosophy

No queremos:

```text
random events for entertainment
```

Queremos:

```text
events generated by simulation
```

---

Ejemplo incorrecto:

```text
Driver is sad today.
```

Ejemplo correcto:

```text
Driver unhappy after losing #1 status.
```

---

# Event Definition

Un evento representa un hecho relevante del mundo.

Todo evento debe tener una causa identificable.

---

# Event Severity

Los eventos poseen un nivel de importancia.

---

## INFO

No requiere acción.

---

## MINOR

Impacto pequeño.

---

## MEDIUM

Puede influir decisiones.

---

## MAJOR

Puede afectar la temporada.

---

## HISTORIC

Puede afectar la historia del juego.
